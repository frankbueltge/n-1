*KsK T3: the regime of a core proposition, the translation test, new statements, the order-words of the field and the pass-words beneath
them (ATP 76-82, 110, 145-148, via KsK §4.2 and ch. 6). Failure: the translation test changes only the wording, not the project's design.
Each entry dated; earlier entries stand.*

## Entry 1 — 2026-11-04, session 1, written before the count

**The proposition.** The checklist's: "*X* is a synonym of *Y*." Its speaker is an institution speaking for a consensus ("a global
consensus view", Govaerts et al. 2021); its grammar is the code of nomenclature (priority from 1753, types, legitimacy), which this
project does not quote and will not paraphrase beyond what the columns show.

**Regime.** Signifying with a postsignifying edge (ATP 147, via KsK T3): every name refers to a centre (the code, the type specimen),
and a judgment of synonymy is a verdict — the judge's sentence that turns the accused into a convict (ATP 80-81) — dated, instantaneous,
and touching no body: the plant stays as it was, a name stops being its name. The first publication was already such a transformation:
a specimen became a species on a page.

**Translation test, planned.** The count translates the verdicts out of their regime — from a ruling per name into a curve per year:
what share of each year's acts of naming still stand. What passes (ATP 147): whether a year's naming survives as a body, independent of
any one name. What will not pass, stated now: the reason a name fell (the argument in a monograph), which no column holds.

**Order-words of the field, named now.** "Accepted"; "Synonym"; "Illegitimate"; "Unplaced" (a name the consensus has not ruled on — a
verdict withheld). **Pass-word to look for** (ATP 110): the basionym, the epithet that passes from one name into the next and survives the
verdict on its first name — the component of passage through which a sunk name keeps standing in another.

**Failure watch.** If the curve only redescribes the verdicts and changes nothing in session 2's design, T3 has triggered.
