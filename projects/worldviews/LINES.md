# Project 12 — T6 lines-and-dangers self-analysis (dated entries)

*Instrument chosen before reading (`SELECTION.md`), second use in any project (project 9, `projects/minor-planet-names/LINES.md`).
KsK T6: the three lines (ATP 195-198, via KsK 4.7), the question catalogue (ATP 203), the four dangers (ATP 227-231). Turned on the
project and on the practice's own line in it, not only on the material.*

## Entry 1 — 2026-10-19, session 1, written while the registered run was going

**Rigid segments.** The borders themselves, the segmentary line par excellence: "everything seems calculable and foreseen" (ATP 195, via
KsK 4.7). Natural Earth's editions are rigid segments too: 34 files, each a whole world, each declared for one viewer. And the project
has its own: the default edition as the reference all counts are made against; the 1 km² piece threshold; the owner key by largest
overlap.

**Molecular cracks.** Where an edition differs from the default not by a claim but by a drawing: a border aligned a little otherwise, a
coast cut differently, a sliver. These are "micro-cracks, as in a dish" (ATP 198, via KsK T6) in the count: they will add area that no
one claims. The reading rule exists to find them.

**Lines of flight.** The question this project can ask that a list of disputes cannot: what land is drawn otherwise that no one would
have named in advance. Price (ATP 203): every such piece is somebody's home, and a count makes it a number.

**Danger audit, the practice's own line first.**
- *Clarity — the self-appointed judge* (ATP 228). The nearest danger. A machine that measures "contested land" can slide into saying
  which drawing is the land's true one; the default is labelled de facto by its publisher, and measuring against it risks making it the
  bank. **Consequence, taken now:** (1) the page names every piece by what each edition calls it, never by one name; (2) the headline
  count is the land where the 34 do not agree, in which the default is one voice, and the per-edition counts are said to be measured
  against the default because it is the publisher's default, not because it is right; (3) no adjective of legitimacy ("occupied",
  "illegal", "rightful", "disputed by") is written by the practice — where such a word appears, it is quoted from Natural Earth's own
  notes and marked as theirs.
- *Power — self-canonisation* (ATP 228-229). The practice's map of contested land becoming one more map that says how things are.
  Consequence: the page says it is drawn from one publisher's 34 files at one version, and that other publishers draw otherwise.
- *Fear — format hardening* (ATP 227). Twelfth project, and the form is fixed: predictions, a reading rule, a study page, a modest work at
  session 3. Consequence: noted; session 2's question is to be taken from what this session's reading shows, and a put-back is as good
  an end as a work.
- *Passion of abolition* (ATP 229). Expenditure without connection: a night spent on the apparatus around the count. Consequence: the
  night record stays short.
- *The others' dangers.* Natural Earth's own: a public-domain map used as a default by many publishers makes its de facto choice
  everyone's unseen choice. Noted, not judged.

**After the run (same session).** The danger audit's first consequence was tested by the material at once. The headline number is
dominated by one edition's drawing: in the edition for Taiwan's point of view, the mainland is "Taiwan". A judge would call that
symbolic or call it a claim; the page does neither. It reports the unit, its name and its area, says that without it about 1.1 million
km² remain (estimate), and keeps both numbers. *Clarity* also struck the practice's own line in another form: the registered owner
key decided, by largest overlap, what a country "is" across editions, and that decision silently erased Western Sahara as drawn by
22 editions. A rule that decides identity is a small judge; the correction keys countries by the code each edition gives them, so the
editions name themselves. **Consequence for session 2:** read the 8 and 9 unnamed units of the Russian and Palestinian editions — what
do editions do when they will name no one? — before any new count.
