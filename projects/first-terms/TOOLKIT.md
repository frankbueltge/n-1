# Project 24, First Terms — toolkit account (work)

*Written 2026-11-17, session 4, when the project closed (DOWRY.md, 2026-09-24). Also carried as edges in atlas layer `2026-11-17`.*

**Result.** The On-Line Encyclopedia of Integer Sequences (CC BY-SA 4.0), its files of shown terms and names, fetched four times
(2026-11-10 to 2026-11-16). Session 1: by beginnings, median six terms to tell a sequence apart; 1.46 % never told apart. Session 2: by
the box's own rule, about 2 % can never be its only answer, the best-known among them. Session 3: what holds what — the most-held are
short entries nobody names; the more an entry is named, the likelier it cannot be found alone. Session 4: **declared a work, *Never the
Only Answer***, the box restaged with only those entries, each answered with everything that holds it.

**Postulates that carried it.** P3 (following): the question moved each session with the material — beginnings (1), the box's rule (2),
holdings (3), the act of asking (4); none of the moves was in the selection. P2 (map, not copy): the work is the material's own instrument
with its contents changed, not a picture of it. P6 (caution): every holding confirmed by the terms, twice tonight; nothing on the page
says why an entry is held — the editors' habit stays conjecture.

**Instruments.** T1 (mapping protocol): the map moved the next decision in every session, and in session 3 moved the work's form away

**What the grammar could not do on this material.** It could not see the editors: why an entry is entered again with a 1 in front, or
kept after it is found to be a duplicate, is not in the files. It could not read the real box's order of answers. It could not test the
work on a person; nobody has looked at it. The material passed no stake test — it was taken before the act of 2026-11-14, and the
honest answer to that act's question is that what this project found affects mainly the people who keep and use the file.

**What this project shows about how a machine can support a person's artistic research.** An exhaustive negative: a person asks the box
one query at a time and sees only what comes back; a machine can ask every query the material allows and return the set of queries that
cannot succeed — a list a researcher can take up as material in its own right, here an instrument restaged around its own failures.

**Where a return would start (a new problem, not a continuation).** The editors' remainder: the 1,140 held entries that call themselves
duplicates, erroneous or variants, read against the entries' edit histories.

predictions were mostly checks on numbers near session 3's, and say so.
